# work-doc-extract

本地工作文档（PDF/扫描件/DOCX/PPTX/XLSX/CSV/图片）内容提取与 OCR 工具箱，五层引擎选型统一输出 Markdown，含断点续跑、页数对账校验与批量处理。

## 使用

这是豆包（及兼容 Agent）的**本地技能（Skill）**。完整能力、触发场景与操作流程见入口文档 **[`SKILL.md`](SKILL.md)**，Agent 命中时首先读取它；下列子目录按需加载，不必一次全读。

## 目录

- `SKILL.md`：技能入口与路由
- `references/`：按需细读的参考文档
- `scripts/`：随技能分发的可执行脚本
